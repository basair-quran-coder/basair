# بصائر V6.48 — التطبيق الخفيف

هذه هي حزمة النشر الكاملة لـ GitHub Pages.

## طريقة العمل

- يُفتح التطبيق ويُثبَّت أولًا من ملف تشغيل خفيف نسبيًا.
- صفحات المصحف الـ604 موجودة في مجلد `mushaf-pages` ولا تُحمَّل كلها عند فتح التطبيق.
- يضغط القارئ زر «تنزيل المصحف» من داخل التطبيق إذا أراد العمل دون اتصال.
- تظهر النسبة وعدد الصفحات، ويستطيع القارئ استكمال التنزيل بعد انقطاع الاتصال.

## النشر

ارفع جميع محتويات هذا المجلد إلى جذر موقع بصائر في GitHub، مع المحافظة على أسماء المجلدات والملفات. لا ترفع `index.html` وحده لأن صفحات المصحف والأيقونات وملف التثبيت مطلوبة معه.

بعد النشر، افتح الموقع مرة واحدة مع الاتصال بالإنترنت. ولتجديد الأيقونة على الآيفون أو الآيباد بعد التحديث، احذف اختصار بصائر القديم من الشاشة الرئيسية ثم أضف الموقع إلى الشاشة الرئيسية مرة أخرى.
